**Estado:** Aprobado
**Autor:** Cauce
**Fecha:** 13 de agosto de 2026
**Stack:** React (frontend) + Node.js (backend) + Supabase (Auth + PostgreSQL)

---

## 1. Resumen / Problema a resolver

Hoy la mayoría de los inversores en Argentina llevan su portfolio en un **Excel/Google Sheets manual**, actualizando precios a mano y calculando rendimiento en pesos y dólares con fórmulas propias. Esto es propenso a errores, no tiene login/seguridad, no es accesible desde el celular de forma cómoda, y no escala.

**Objetivo del producto:** una web app segura, con login, donde el usuario carga (al principio manualmente) sus activos — acciones, CEDEARs, cripto, FCI, bonos, plazo fijo, etc. — y ve su portfolio consolidado, valuado tanto en **ARS** como en **USD**, con rendimiento histórico y por activo.

**Filosofía del MVP:** interactivo y rápido de construir. Carga 100% manual, con login social para no reinventar auth. Los precios automáticos y las integraciones con brokers quedan para fases posteriores.

## 2. Alcance del MVP

### Incluye
1. **Login** con Google (Supabase Auth).
2. **CRUD de activos**: tipo (acción, CEDEAR, cripto, FCI, bono, plazo fijo, otro), ticker/nombre, moneda de compra.
3. **CRUD de transacciones** (compras/ventas): cantidad, precio, moneda, fecha.
4. **Carga manual del último precio** por activo.
5. **Tipo de cambio automático** vía DolarAPI (oficial/blue/MEP/CCL), configurable por usuario.
6. **Dashboard del portfolio**: valor total en ARS y en USD, distribución por tipo de activo (torta), tabla de posiciones con rendimiento ($ y %) por activo, curva de evolución histórica.
7. Precios de cripto automatizados vía CoinGecko para los tickers soportados.

### Fuera del MVP
- Integraciones automáticas con brokers/exchanges.
- Multi-portfolio / multi-cuenta.
- Cálculo impositivo.
- Alertas de precio.
- App mobile nativa.

## 3. Arquitectura

```
┌─────────────────────┐         ┌──────────────────────┐        ┌─────────────────┐
│   React (Vite)       │  HTTPS  │   Node.js + Express     │  SQL   │  PostgreSQL       │
│   - Dashboard         │◄───────►│  - REST API            │◄──────►│  (Supabase)       │
│   - CRUD de activos   │  JWT    │  - Auth (Supabase)     │        │                   │
│   - Gráficos          │         │  - Cálculo rendimiento │        │                   │
└─────────────────────┘         └──────────┬───────────┘        └─────────────────┘
                                             │
                                             ▼
                                 ┌──────────────────────┐
                                 │ DolarAPI · CoinGecko  │
                                 └──────────────────────┘
```

- **Frontend:** React + Vite + TypeScript + Tailwind + TanStack Query + React Router + Recharts
- **Backend:** Node + Express + TypeScript + Prisma + zod
- **Auth/DB:** Supabase (Auth + PostgreSQL)
- **Datos:** DolarAPI (tipo de cambio), CoinGecko (cripto)

## 4. Modelo de datos

```
User               Asset                  Transaction              PriceSnapshot           PortfolioSnapshot
----               -----                  -----------              -------------           -----------------
id                id                     id                       id                     id
email             user_id                asset_id                 asset_id               user_id
name              type                   type (compra|venta)      price                  total_ars
avatar_url        ticker                 quantity                 currency               total_usd
fx_reference      name                   price                    updated_at             date
                  currency_bought        currency
                  created_at             date
```

Permite calcular por activo: `cantidad = Σ compras − Σ ventas`, `costo`, `valor = cantidad × último precio`, `rendimiento = valor − costo`.

## 5. Roadmap

- **Sprint 0 — Setup:** mono-repo yarn, scaffolding, Prisma, `.env.example`. ✅
- **Sprint 1 — Auth:** login con Google, rutas protegidas, modelo `User`. ✅
- **Sprint 2 — CRUD de activos y transacciones:** endpoints REST + formularios en React. ✅
- **Sprint 3 — Valuación y tipo de cambio:** DolarAPI, selector de dólar de referencia, carga manual de precios. ✅
- **Sprint 4 — Dashboard:** totales ARS/USD, gráficos de distribución y evolución. ✅
- **Sprint 5 — QA y lanzamiento:** estados vacíos, responsive, deploy.

## 6. Fases futuras

1. **Fase 2 — Precios automáticos:** CoinGecko (cripto), BYMAdata o alternativa para acciones/CEDEARs, CAFCI para FCI.
2. **Fase 3 — Integraciones con brokers/exchanges** (IOL, Cocos, Binance).
3. **Fase 4 — Analítica avanzada:** rendimiento ponderado por tiempo (TWR), comparación contra índices, reportes impositivos.
4. **Fase 5 — Multi-portfolio, alertas, exportación, app mobile.**
